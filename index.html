오늘 우리동네 아이 돌봄·놀이 찾기

국가서비스부터 키즈카페까지 한 번에

AI 검색은 하루 5회까지 테스트 가능합니다.

서비스 지역 확장 중 초기에는 동탄·홍성·예산 등 테스트 데이터가 있는 지역부터 먼저 고도화합니다.

핵심 필터

카테고리

0곳
우리 기관 무료 등록하기 초기에는 광고보다 무료 등록으로 검수 데이터를 먼저 채웁니다.

오늘 추천 장소

전화 확인 필요 · 예약링크 있음 · 당일 가능성

지도 보기

카카오맵 SDK는 지도 배경과 자체 DB 좌표 마커 표시용으로 사용할 수 있습니다. 카카오/네이버/예약 플랫폼의 장소 정보를 수집해 저장하지 않습니다.

AI 추천 검색

AI는 전체 판단을 대신하지 않고, DB 필터링 후 후보 5~10개를 짧게 정리하는 역할만 합니다.

검색어와 필터를 바탕으로 후보를 정리합니다.
AI 검색은 /api/ai-search 같은 서버리스 함수에서 처리한다. OpenAI/Claude API Key는 Vercel/Netlify/Cloudflare/Supabase Edge Function 환경변수에 저장하고, 프론트에는 노출하지 않는다.

등록·수정·광고 문의

출시 초기에는 광고 판매보다 무료 등록 신청을 먼저 받습니다. 업체 로그인은 넣지 않고, 신청폼 접수 후 수동 검수로 반영합니다.

외부 사이트 상세정보를 자동으로 긁어와 저장하지 않습니다. 공공데이터, 지자체 오픈데이터, 공식 API, 공식 홈페이지 링크, 업체 직접 등록, 수동 검수 데이터를 중심으로 확장합니다.

서비스 원칙

  • 회원가입 없이 부모 사용자가 바로 검색합니다.
  • 자체 예약·결제·실시간 잔여석 연동은 초기 버전에 넣지 않습니다.
  • 잔여석은 안전하게 “전화 확인 필요”, “예약링크 있음”, “당일 가능성”으로 표시합니다.
  • 등록폼에서 받는 담당자명·연락처는 내부 검수용으로만 쓰고 공개 화면에는 노출하지 않습니다.

데이터 안전 기준

장소명, 주소, 대표전화, 공식 홈페이지, 운영시간 정도를 중심으로 관리하고, 상세 설명은 자체 작성 또는 업체 제공 문구만 사용합니다.
