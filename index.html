🔒 개인정보처리방침 및 이용약관

제1조 개인정보 수집 및 이용

오늘아이돌봄(이하 "서비스")은 현재 회원가입 없이 운영되며, 별도의 개인정보를 수집하지 않습니다. 단, 업체 등록 신청 시 입력된 사업자 정보 및 연락처는 서비스 검토 목적으로만 사용되며, 검토 후 즉시 파기됩니다.

제2조 장소 정보의 출처 및 정확성

본 서비스에 표시되는 장소 정보(업체명, 주소, 전화번호, 위치)는 카카오맵 Places API를 통해 실시간으로 제공됩니다. 해당 데이터는 카카오의 서비스 약관에 따라 제공되며, 본 서비스는 데이터의 정확성·완전성·최신성을 보장하지 않습니다.

⚠️ 실제 운영 여부, 영업시간, 휴업 여부는 반드시 해당 업체에 직접 확인하시기 바랍니다.

제3조 카카오맵 API 이용

본 서비스는 카카오 JavaScript Map API 및 Places API를 이용합니다. 검색 결과 데이터는 카카오 이용약관에 따라 실시간 표시 목적으로만 활용되며, 별도 저장·재배포하지 않습니다.

제4조 서비스 이용약관

① 본 서비스는 육아 시설 정보 제공을 목적으로 하며, 상업적 목적의 무단 크롤링·스크래핑을 금지합니다.
② 서비스에 표시된 업체 정보로 인한 손해에 대해 운영자는 책임을 지지 않습니다.
③ 서비스 운영자는 사전 고지 없이 서비스를 변경·중단할 수 있습니다.

제5조 업체 정보 삭제 요청

카카오맵에 등록된 업체 정보의 수정·삭제는 카카오맵(place.map.kakao.com)에서 직접 신청하시기 바랍니다. 본 서비스는 카카오맵 API를 통해 실시간으로 데이터를 표시하므로, 카카오맵에서 수정되면 본 서비스에도 자동 반영됩니다.

제6조 쿠키 및 로컬스토리지

본 서비스는 검색 결과 캐싱을 위해 브라우저 sessionStorage를 사용합니다. 이는 사용자의 기기에만 저장되며, 서버로 전송되지 않습니다. 브라우저 탭을 닫으면 자동 삭제됩니다.

시행일

본 약관은 2025년 1월 1일부터 시행됩니다.

📋 이용약관

제1조 목적

본 약관은 오늘아이돌봄 서비스 이용에 관한 조건 및 절차를 규정합니다.

제2조 서비스 이용

① 본 서비스는 수도권 육아 시설 정보를 제공하는 정보 조회 서비스입니다.
② 서비스 이용은 무료이며, 별도의 회원가입이 필요하지 않습니다.
③ 상업적 목적의 데이터 수집(크롤링·스크래핑)은 금지됩니다.

제3조 정보의 정확성

장소 정보는 카카오맵 API를 통해 실시간 제공되며, 정확성을 보장하지 않습니다. 실제 방문 전 업체에 직접 확인하시기 바랍니다.

제4조 면책

서비스에 표시된 정보로 인한 직·간접적 손해에 대해 운영자는 법적 책임을 지지 않습니다.

🏪 업체 등록 신청
⚠️ 업체 등록 신청 후 관리자 검토 (1~3 영업일)를 거쳐 등록됩니다.
허위·부정확한 정보 등록 시 승인이 거부될 수 있습니다.
카카오맵에 등록된 업체는 자동으로 검색에 표시됩니다.
