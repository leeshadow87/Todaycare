🔑 카카오맵 API 키 설정
무료 카카오 개발자 계정으로 실제 지도를 바로 사용할 수 있어요.
설정은 이 브라우저에 저장됩니다.
  1. developers.kakao.com 접속 → 무료 가입
  2. 내 애플리케이션 → 애플리케이션 추가하기
  3. 앱 이름 입력 후 생성 → 앱 키 탭 → JavaScript 키 복사
  4. 플랫폼 → Web 플랫폼 등록 → 사이트 도메인 추가
    (로컬 테스트: http://localhost)
