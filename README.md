# 오늘아이돌봄지도 V12_2

V12_2는 V11_2의 지도/목록 UI를 유지하면서 V12의 출시 정책을 반영한 버전입니다.

## 핵심 방향

- 부모 사용자는 회원가입 없이 바로 검색
- 지도/목록 분할 UI 유지
- 카카오맵은 지도 배경과 자체 DB 좌표 마커 표시용으로만 사용
- 장소 데이터는 공공데이터, 공식 링크, 업체 직접 등록, 수동 검수 중심
- 외부 지도/예약 플랫폼의 상세정보를 자동 수집해 DB화하지 않음
- 업체 등록은 구글폼 접수 후 수동 검수
- AI 검색은 초기 화면 주인공이 아니라 보조 기능으로 두고, 실제 API는 서버리스 함수에서 처리

## GitHub/Vercel 업로드 구조

루트에 아래 구조로 올립니다.

```text
index.html
manifest.json
sw.js
service-worker.js
assets/
data/
icons/
README.md
vendor_registration_manual.md
```

V12_2의 실제 서비스워커는 `sw.js`입니다. `service-worker.js`는 이전 V12 목업을 올렸던 브라우저의 낡은 캐시를 지우는 정리용 파일입니다. `data_v12.json`은 사용하지 않고, V11_2 UI 기반이라 `data/places.json`을 사용합니다.

## 데이터 라벨 기준

- `업체등록`: 업체가 실제로 직접 제출했고 운영자가 검수한 데이터에만 사용
- `공식DB`: 공공데이터·지자체 공개자료 기반
- `외부확인`: 네이버·카카오 등 외부 지도에서 위치 확인이 필요한 링크형 데이터
- `검수샘플`: 출시 전 테스트 데이터에만 사용

## 카카오맵 API 사용 원칙

허용:

- 지도 배경 렌더링
- 자체 DB의 위도/경도 기반 마커 표시
- 장소 카드의 카카오맵 길찾기/검색 링크 연결

금지:

- 카카오 Local/Places API 결과를 장소 DB로 저장
- 네이버지도, 카카오맵, 예약 플랫폼의 장소명, 전화, 사진, 후기, 설명을 자동 수집해 재배포
- API 결과를 장기 보관하거나 자체 데이터처럼 제공

## PWA 상태

- `manifest.json` 포함
- `sw.js` 서비스워커 포함
- 홈화면 추가 가능 구조
- `data/places.json`은 네트워크 우선, 실패 시 캐시
- Google Fonts는 런타임 캐시

## 출시 우선순위

1. 공공데이터 기반 2~3개 지역 데이터 구축
2. 업체 무료 등록 신청폼 오픈
3. 수동 검수 후 DB 확장
4. AI 검색 서버리스 함수 추가
5. Android TWA/WebView 패키징
6. 광고/상단노출 상품 판매
