# 오늘아이돌봄지도 V12_3

V12_3는 V11_2의 지도/목록 UI와 V12_2의 PWA 구조를 유지하면서, 사설 기관 업체등록을 늘리기 위한 전환 요소를 강화한 운영형 MVP입니다.

## 목표

- 부모 사용자는 회원가입 없이 우리 동네 돌봄·놀이 장소를 바로 검색
- 업체·기관은 무료 등록 안내를 보고 구글폼으로 신청
- 운영자는 수동 검수 후 `data/places.json`에 반영
- 광고·상단노출은 DB가 쌓인 뒤 후순위로 진행

## 이번 버전에서 강화한 부분

- 상단 업체등록 버튼을 `무료등록`으로 변경
- 검색/필터 아래에 업체 무료 등록 CTA 추가
- 업체등록 모달에 무료 등록 혜택 문구 추가
- 등록비 0원, 검수 반영, 전화·예약링크 연결을 명확히 표시
- 업체 영업 리스트 템플릿 `vendor_outreach_list_template.csv` 추가

## GitHub 업로드 구조

ZIP을 풀면 아래 파일과 폴더를 GitHub 저장소 루트에 올립니다.

```text
index.html
manifest.json
sw.js
service-worker.js
assets/
data/

README.md

```

V12_3의 실제 서비스워커는 `sw.js`입니다. `service-worker.js`는 이전 V12 목업을 올렸던 브라우저의 낡은 캐시를 지우는 정리용 파일입니다.

## 데이터 라벨 기준

- `업체등록`: 업체가 실제로 직접 제출했고 운영자가 검수한 데이터에만 사용
- `공식DB`: 공공데이터포털, 지자체 공개자료, 기관 공식자료 기반
- `외부확인`: 네이버·카카오 등 외부 지도에서 위치 확인이 필요한 링크형 데이터
- `검수샘플`: 출시 전 테스트 데이터에만 사용

## 카카오맵 사용 원칙

카카오맵 SDK는 지도 배경 렌더링과 자체 DB 좌표 마커 표시용으로만 사용합니다.

하지 않는 것:

- 카카오 Local/Places API 검색 결과를 장소 DB로 저장
- 네이버지도, 카카오맵, 예약 플랫폼 정보를 대량 복제
- 민간 사이트 상세 설명, 사진, 후기, 전화번호를 자동 수집해 재배포

하는 것:

- 자체 DB의 위도/경도를 지도 위 마커로 표시
- 공공데이터, 공식 링크, 업체 직접 등록, 수동 검수 데이터 사용
- 외부 사이트는 원문 복제 대신 링크로 연결

## 업체등록 운영 순서

1. 지역별 사설 기관 후보를 `vendor_outreach_list_template.csv`에 정리
2. 인스타그램 DM, 전화, 카카오채널, 이메일로 무료 등록 안내
3. 구글폼 접수
4. 운영자 수동 검수
5. `data/places.json`에 `operator_registered: true`로 반영
6. 30개 이상 실제 등록 후 업체관리/자동 DB 반영 검토

## PWA 상태

- `manifest.json` 포함
- `sw.js` 캐시 전략 포함
- 아이콘 192/512 포함
- `data/places.json`은 네트워크 우선, 실패 시 캐시

Google Play 출시는 업체등록 반응 확인 후 TWA 방식으로 진행하는 것을 권장합니다.
