# 오늘아이돌봄지도 V12

V12는 `PWA 먼저 완성 → 추후 Android TWA/WebView 패키징`을 기준으로 만든 모바일 우선 구조입니다.

## 핵심 포지션

오늘아이돌봄지도는 국가 아이돌봄서비스, 공공돌봄, 민간 키즈카페, 실내놀이터, 도서관 프로그램, 체험수업, 학원 단기특강을 한 번에 찾는 우리동네 돌봄·놀이 통합 검색 지도입니다.

국가 아이돌봄서비스는 경쟁 서비스가 아니라 `공식 방문형 1:1 돌봄 연결` 카테고리로 둡니다.

## 출시용 UX 우선순위

모바일 첫 화면은 너무 많은 선택지를 한 번에 보여주지 않습니다.

1차 카테고리:

- 공공돌봄
- 실내놀이
- 프로그램·수업
- 체험·나들이

세부 카테고리:

- 국가 아이돌봄서비스
- 키즈카페
- 실내놀이터
- 도서관 프로그램
- 체험수업
- 학원 단기특강
- 공동육아나눔터
- 가족센터
- 방학특강
- 농촌체험·숲체험·키즈쿠킹

1차 필터:

- 오늘 가능
- 실내
- 4~7세

나머지 필터는 `세부 필터 더보기`로 접어둡니다.

## 데이터 공백 대응 전략

초기에는 전국 전체를 완벽하게 채우기보다 데이터 밀도가 있는 지역부터 선노출합니다.

권장 순서:

1. 동탄, 홍성, 예산 등 테스트 지역 데이터 구축
2. 공공데이터 기반 2~3개 지역 고도화
3. 업체 무료 등록 신청폼 오픈
4. 수동 검수 후 DB 확장
5. 데이터가 부족한 지역에는 `현재 서비스 지역 확장 중` 안내 표시

## 파일 구조

- `index_v12.html`: 모바일 우선 PWA 화면
- `assets/v12.css`: V12 전용 스타일
- `assets/v12.js`: 검색, 필터, 카드, AI 제한형 흐름
- `data_v12.json`: V12 샘플 데이터와 데이터 구조
- `manifest.json`: 홈화면 추가/TWA 고려 PWA 설정
- `service-worker.js`: 정적 자산과 데이터 캐시
- `업체등록_모바일_웹_매뉴얼.md`: 업체등록 운영 매뉴얼

## 안전한 데이터 원칙

사용 가능성이 높은 방식:

- 공공데이터포털
- 지자체 오픈데이터
- 기관 공식 API
- 공식 홈페이지 링크
- 업체 직접 등록 신청
- 수동 검수 데이터

피해야 할 방식:

- 네이버지도, 카카오맵, 예약 플랫폼, 민간 사이트 상세정보를 자동 대량 크롤링해 DB화
- 사진, 후기, 설명, 개인 연락처를 무단 저장
- 외부 사이트 내용을 복제해서 자체 데이터처럼 제공

## 카카오맵 API 사용 원칙

카카오맵 SDK는 빼지 않습니다. 초기 국내 서비스에서는 지도 배경과 마커 표시용으로 현실적인 선택입니다.

허용:

- 지도 배경 렌더링
- 자체 DB에 있는 위도/경도 기반 마커 표시
- 장소 카드의 길찾기 외부 링크 연결

금지:

- 카카오 Local/Places API 검색 결과를 장소 DB로 저장
- 카카오맵, 네이버지도, 예약 플랫폼의 장소명, 주소, 전화, 사진, 후기, 설명을 자동 수집해 재배포
- API 결과를 장기 보관하거나 자체 데이터처럼 제공

구현 원칙:

- `카카오맵 = 지도 화면`
- `장소 데이터 = 자체 DB, 공공데이터, 공식 API, 업체 직접 등록, 수동 검수`
- 지도 SDK 키는 공개될 수 있으므로 카카오 개발자 콘솔에서 허용 도메인을 반드시 제한
- 지도 제공자는 Kakao/Naver/Google/Leaflet으로 바꿀 수 있게 얇은 어댑터 계층으로 분리

## AI 검색 구조

프론트에는 API 키를 넣지 않습니다.

AI 검색은 `/api/ai-search` 같은 서버리스 함수에서 처리해야 합니다. OpenAI/Claude API Key는 Vercel, Netlify, Cloudflare, Supabase Edge Function 환경변수에 저장하고 프론트에는 노출하지 않습니다.

현재 V12 프론트는 하루 5회 localStorage 제한과 DB 후보 정리 흐름만 구현했습니다.

- `manifest.json`, `service-worker.js` 충돌에 주의
